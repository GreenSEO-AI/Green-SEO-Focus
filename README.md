## 🌿 Description

Green SEO Focus est une application de productivité développée pour aider les étudiants OpenClassrooms et professionnels du web à maximiser leur concentration et réduire les distractions. Conçue avec une interface élégante et intuitive, elle permet de suivre vos tâches, bloquer les distractions, et générer des rapports détaillés de votre productivité.

## ✨ Fonctionnalités principales

- **Suivi du temps** : Minuteur personnalisable pour chaque tâche avec rappels réguliers
- **Blocage des distractions** : Détection et blocage des sites de réseaux sociaux pendant les sessions de travail
- **Gestion des notifications** : Désactivation temporaire des notifications système pendant vos sessions de focus
- **Configuration Discord** : Paramètres spéciaux pour éviter les distractions de Discord
- **Rapports détaillés** : Génération automatique de rapports au format Markdown
- **Visualisations analytiques** : Graphiques de productivité quotidienne, heatmap des heures de travail
- **Export versatile** : Compatibilité avec Notion, Trello et autres outils de gestion de projet

## 🚀 Installation

L'application est disponible sous forme d'exécutable Windows autonome. Aucune installation complexe n'est nécessaire.

1. Téléchargez le fichier `.exe` depuis la page des [releases](https://drive.google.com/file/d/1CxHbPWrb8RYOo1AGtlGxEtnFEZKEpAU4/view?usp=sharing)
2. Exécutez l'application (l'icône reconnaissable avec l'œil vert apparaîtra)
3. Commencez immédiatement à suivre vos tâches et améliorer votre productivité

## 🔍 Comment utiliser Green SEO Focus

1. **Définir une tâche** : Entrez le nom de votre tâche actuelle
2. **Régler la durée** : Paramétrez le temps entre chaque rappel (en minutes)
3. **Activer les protections** : Cochez les options pour bloquer les distractions et notifications
4. **Démarrer la session** : Cliquez sur "Démarrer la tâche" et concentrez-vous sur votre travail
5. **Terminer la tâche** : Marquez la tâche comme terminée une fois votre travail accompli
6. **Générer un rapport** : Créez un rapport détaillé de votre session de travail
7. **Analyser votre productivité** : Visualisez vos données avec les graphiques intégrés

L'application génère quatre types de visualisations pour vous aider à comprendre vos habitudes de travail :

- **Productivité quotidienne** : Suivez vos heures de travail jour par jour
- **Heatmap de travail** : Identifiez vos périodes les plus productives de la semaine
- **Types de tâches** : Analysez la répartition de votre temps par catégorie de tâche
- **Tâches courtes** : Repérez vos tâches les plus rapides à accomplir

Ces graphiques peuvent être exportés pour être utilisés dans vos outils préférés :
- **Notion** : Créez des tableaux de bord visuels de productivité
- **Trello** : Ajoutez-les à vos cartes pour suivre votre progression
- **GitHub** : Intégrez-les à vos READMEs pour documenter l'avancement du projet

## 🔄 Intégration avec les IA conversationnelles

Les rapports générés au format Markdown sont optimisés pour être analysés par des assistants IA comme Claude ou ChatGPT. Partagez simplement votre rapport avec l'IA pour obtenir :

- Analyse de vos tendances de productivité
- Conseils personnalisés pour améliorer votre efficacité
- Identification des moments optimaux pour programmer des tâches difficiles
- Suggestions pour équilibrer différents types de tâches

## 🔧 Utilisation pour les étudiants OpenClassrooms

Green SEO Focus est particulièrement adapté aux étudiants OpenClassrooms :

- **Suivi des projets** : Documentez le temps passé sur chaque projet pour votre mentor
- **Focus sur l'apprentissage** : Éliminez les distractions pendant vos sessions d'étude
- **Preuves d'activité** : Générez des rapports détaillés à partager avec votre mentor
- **Planification efficace** : Identifiez vos périodes optimales pour étudier
- **Équilibre vie/études** : Visualisez votre investissement dans votre formation
